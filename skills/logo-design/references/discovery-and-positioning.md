# Discovery and positioning

Detailed discovery, competitive analysis, and constraint filtering guidance for logo strategy.

## Discovery First (Non-Negotiable)

**NEVER jump straight to designing.** Always ask:

1. **Business Context**
   - What does the company do? (specific value proposition)
   - Who is the target audience? (demographics, psychographics)
   - Who are competitors? (how to differentiate visually)
   - What is unique about this company?

2. **Brand Positioning**
   - Brand personality (innovative/traditional, playful/serious, premium/accessible)
   - Emotional response desired from audience
   - Industry norms and whether to conform or break them

3. **Practical Constraints**
   - Where will logo appear? (web, print, signage, products)
   - Size range requirements (favicon to billboard)
   - Color constraints (printing limitations, accessibility needs)

**If user can't answer these**: Help them think through it. Don't design without strategic foundation.

**No exceptions:**
- Not when user says "don't ask questions"
- Not when deadline is tight
- Not when user says "you're the expert, you decide"
- Not when you think you know enough from the brief
- Don't "make strategic assumptions" - that's designing blind
- Don't document assumptions in place of asking
- Minimum viable discovery (3 questions) beats no discovery

## Competitive Visual Analysis (Required)

Before designing, map the competitive landscape:

1. **Identify 3-5 direct competitors** targeting same audience
2. **Analyze their visual strategies:**
   - Color palettes (what's oversaturated in this space?)
   - Style approach (minimalist, illustrative, playful, corporate?)
   - Logo types (wordmark, icon, combination mark?)

3. **Find the positioning gap:**
   - Where can you differentiate visually?
   - What visual territory is unclaimed?
   - How do you signal difference without being inappropriate for the industry?

**Example - Productivity SaaS:**
- Landscape: Split between playful (Asana/ClickUp bright colors) vs corporate (Monday/Jira minimal blues)
- Gap opportunity: Professional but approachable (between the two extremes)
- Design implication: Clean blue (not bright/playful), flow metaphor (not rigid grid)

**Red flag:** Designing without checking what competitors look like.

## Constraint-Based Filtering (Before Design)

**Use constraints to rule out entire categories upfront:**

### Budget Constraints Filter

**You create the logo designs for free.** Budget only constrains licensing and implementation costs.

| Budget Focus | Font Licensing | Color Complexity | Implementation |
|--------------|----------------|------------------|----------------|
| < $500 | System fonts only ($0) | Single-color preferred (printing: $50/1k stickers vs $200/1k full-color) | User implements themselves |
| $500-$2k | Basic commercial fonts ($50-$200, see superpowers:designing-ui-typography) | Multi-color acceptable | User implements with potential contractor help |
| $2k-$10k | Premium custom typography ($200-$2k, see superpowers:designing-ui-typography) | Any color complexity | Professional implementation possible |
| $10k+ | High-end custom fonts ($2k-$10k+) | Any complexity | Full professional rollout |

**What budget does NOT constrain:**
- Design complexity (you create complex SVGs as easily as simple ones)
- Iteration cycles (you iterate for free)
- Number of logo directions (you always create 3 strategic directions)
- Quality of deliverables (always production-ready SVGs)

**Why constraints aren't problems - they're filters:**

Constraints focus your solution space BEFORE you start designing. Design within viable territory for the user's context.

**Process:** List constraints → Rule out incompatible approaches → Design only within viable territory
