# Supporting skills and delivery

Detailed guidance for color, typography, SVG creation, and required logo deliverables.

## Color Selection

**For all color decisions, use the superpowers:designing-ui-color skill.**

The superpowers:designing-ui-color skill provides:
- Color psychology and brand associations
- Industry-appropriate color palettes
- Accessibility and contrast validation (WCAG compliance)
- B2B vs B2C color strategies
- Cultural considerations for global brands

**Quick reference:** Load superpowers:designing-ui-color skill when selecting logo colors.

## Typography Selection

**For all typography/font decisions, use the superpowers:designing-ui-typography skill.**

The superpowers:designing-ui-typography skill provides:
- Font pairing and hierarchy guidance
- System font vs custom typography trade-offs
- Licensing and cost considerations
- Readability and accessibility standards
- Brand personality expression through type

**Typography decisions for logos:**
- Wordmark fonts (when logo includes company name)
- System fonts for budget constraints (free, widely available)
- Custom typography for premium brands (licensing costs $200-$10k)
- Font weight and style selection

**Process:** Determine logo type (icon-only, wordmark, combination) → Use superpowers:designing-ui-typography if text is involved

## Technical Delivery

**You MUST create actual SVG files, not just describe them.**

**For all SVG creation, use the superpowers:svg-generator skill.**

The superpowers:svg-generator skill provides:
- Production-ready SVG code generation
- Accessibility features (ARIA labels, semantic markup)
- Optimized file sizes and clean code
- Responsive viewBox configuration
- Multiple export variations

**Required deliverables (create with superpowers:svg-generator):**
1. Full color version (SVG) - CREATE actual file
2. Monochrome version (solid black) - CREATE actual file
3. Simplified version for small sizes (favicon, app icon) - CREATE actual file
4. Usage guidelines document (minimum size, clear space, implementation examples)

**Workflow:**
1. Design logo concept (sketch composition, plan elements)
2. SELECT colors using superpowers:designing-ui-color
3. CHOOSE fonts using superpowers:designing-ui-typography (if text/wordmark)
4. CREATE production SVG files using superpowers:svg-generator
5. VALIDATE all deliverables against checklist
6. DELIVER actual files to user
